# Snowfallen · 雪放

《杀戮尖塔 2》（Slay the Spire 2）的雪放角色模组，分别提供 Beta 和正式版源码及安装包。

## 下载游玩

在仓库网页点击 **Releases → 对应版本 → Assets**，下载名称包含 `Snowfallen` 和 `beta` 或 `stable` 的 ZIP。不要将自动生成的 **Source code (zip)** 当作完整安装包。首次发布前可能尚无附件。

先阅读 [安装说明](docs/INSTALL.md)。本版沿用 Snowfallen 模组 ID，只安装匹配分支的一份，不能与其他同 ID 版本同时启用；请新开局，不直接载入包含已移除内容的旧档。

## 包含内容

保留雪放角色、雪放所需共享机制、通用遗物和原有通用药水。当前保留 89 个卡牌模型（含生成牌和隐藏旧牌）、23 个遗物模型、11 个药水模型；这些模型数量不是选人卡池的可选牌数量。

| 路径 | 内容 |
| --- | --- |
| `src/beta` | Beta 游戏 API 对应的雪放源码、本地化和模组清单 |
| `src/stable` | 正式版游戏 API 对应的雪放源码、本地化和模组清单 |
| `docs/BUILD.md` | 编译环境和依赖配置 |
| `docs/INSTALL.md` | 完整 ZIP 的安装方法 |
| `docs/AI_AND_RIGHTS.md` | MIT 范围、AI 声明和素材说明 |
| `docs/RELEASE_NOTES.md` | 发布整理和验证边界 |
| `docs/MAINTENANCE.md` | 后续源码更新方法 |

两版依赖不同的游戏 API，不要互相覆盖实现或混用 DLL。读取源码不需要安装依赖；编译需要匹配游戏与 BaseLib。缺少美术资源的源码仓库不能直接导出完整 PCK。
