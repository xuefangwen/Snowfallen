## 下载与安装

Beta 游戏下载 beta ZIP；正式版游戏下载 stable ZIP。两版只装一份，需匹配版本的 BaseLib。退出游戏后，将 ZIP 内的 Snowfallen 文件夹放入游戏根目录的 mods，避免同 ID 重复加载，请新开局使用。具体见 [安装说明](INSTALL.md)。
